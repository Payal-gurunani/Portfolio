# 💼 Portfolio Website

A modern, responsive personal portfolio built using **React.js** and styled with **Tailwind CSS / MUI**. Showcases my work, skills, and contact details with clean UI and smooth animations.

## 🔗 Live Demo
[View Live](https://portfolio-three-gamma-5rrw4zw0c2.vercel.app/)

## 🚀 Features
- Responsive design for all devices
- Animated sections with Framer Motion
- Project showcase with links
- Working contact form (e.g., EmailJS)
- Smooth scroll navigation

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS 
- **Animations:** Framer Motion 
- **Deployment:** Vercel 
- **Icons:** Lucide / Font Awesome

## 📂 Setup Instructions
```bash
git clone https://github.com/Payal-gurunani/Portfolio.git
cd portfolio
npm install
npm run dev
```
